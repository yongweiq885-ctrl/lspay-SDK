# 立收通统一网关 way_code

| way_code | 接口代码 / 业务 |
| --- | --- |
| `ALI_BAR` | 支付宝条码 |
| `ALI_PUB` | 支付宝 JSAPI（间连，线上扫码推荐） |
| `ALI_APP` | 支付宝 APP（直连） |
| `ALI_H5` | 支付宝 H5（直连） |
| `ALI_LITE_H5` | 支付宝外或 App 唤起收银台 |
| `ALI_PC` | 支付宝电脑网站（直连） |
| `ALI_QR` | 支付宝扫码（间连，可在支付宝外拉起收银台） |
| `ALI_LITE` | 支付宝小程序（直连） |
| `WX_BAR` | 微信条码 |
| `WX_PUB` | 微信 JSAPI（间连，扫码或公众号） |
| `WX_LITE` | 微信小程序 |
| `WX_APP` | 微信 APP（直连） |
| `WX_LITE_H5` | 微信外或 App 唤起收银台（建议安卓） |
| `WX_LITE_JUMP` | 小程序跳立收通收银台 |
| `WX_NATIVE` | 微信扫码（直连） |
| `YSF_BAR` | 云闪付条码 |
| `YSF_JSAPI` | 云闪付线上（小程序或扫码） |
| `CUP_QR` | 云闪付扫码 |
| `BANK_FAST` | 快捷支付 |
| `BANK_FAST_JUMP` | 快捷支付收银台 |
| `APPLY` | 用户入驻 |
| `BALANCE_PAY` | 余额支付 |
| `BALANCE_QUERY` | 余额查询 |
| `SETTLE_QUERY` | 结算查询 |
| `BALANCE_WITHDRAW` | 余额提现 |
| `WITHDRAW_SINGLE_QUERY` | 单笔提现查询 |
| `WITHDRAW_QUERY` | 批量提现查询 |

普通统一下单只能选择从 `ALI_BAR` 到 `BANK_FAST_JUMP` 的 20 个接口代码。
`APPLY` 及其后的代码只允许由对应专用 Request 使用。

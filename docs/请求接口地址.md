# 请求接口地址

生产网关：`https://api.lspay.tech/`

| 能力 | 路径 |
| --- | --- |
| 统一下单（含快捷支付申请、余额支付） | `gateway/unifiedorder` |
| 订单查询 | `gateway/query` |
| 订单退款 | `gateway/refund` |
| 退款订单查询 | `gateway/refund/query` |
| 延时分账交易确认 | `gateway/delaytrans/confirm` |
| 交易确认退款 | `gateway/delaytrans/confirmrefund` |
| 可转余额查询 | `gateway/delaytrans/unconfirm/query` |
| 延时分账订单转账 | `gateway/delaytrans/createtask` |
| 快捷支付绑卡申请 | `gateway/quickpay/buckleapply` |
| 快捷支付绑卡确认 | `gateway/quickpay/buckleconfirm` |
| 快捷支付确认 | `gateway/quickpay/payconfirm` |
| 快捷支付解绑 | `gateway/quickpay/payunbind` |
| 快捷支付短信校验 | `gateway/quickpay/smscheck` |
| 电子账户用户开通 | `gateway/user/personapply` |
| 电子账户业务开通 | `gateway/user/personconfirm` |
| 电子账户业务变更 | `gateway/user/personmodify` |
| 电子账户用户查询 | `gateway/user/query` |
| 电子账户结算记录查询 | `gateway/user/settlement/query` |
| 电子账户余额提现 | `gateway/user/balance/withdraw` |
| 电子账户单笔提现查询 | `gateway/user/balance/withdraw/single/query` |
| 电子账户批量提现查询 | `gateway/user/balance/withdraw/query` |
| 电子账户余额查询 | `gateway/user/balance/query` |

机器可读的跨语言覆盖基线见 `contracts/endpoints.json`。
